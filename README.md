# River on Record

**The public drain scoreboard for the Yamuna.**

A Vantalyne Labs venture. The river dies in 22 kilometres — we rate the drains that kill it.

- Every drain mapped on a 22 km transect, drawn to scale
- One Drain Health Score (DHS) per drain — 0.70 quality · 0.20 trend · 0.10 load
- Every number traced to a public source: DPCC, DJB, NGT, Delhi DoE
- No invented figures — a drain without usable public data stays unrated

Built on public government data. Next.js 16, TypeScript, Tailwind CSS 4.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Static export (`output: "export"`) deployed to GitHub Pages via `.github/workflows/deploy.yml`.
